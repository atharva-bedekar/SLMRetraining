# V4 Regenerated-Label Experiments (`v4-1325` and `v4-5000`)

**Training, 100-case generation (`gen_rp=1.00_fb1.08`), `gemini-4-hydrogen` source-grounded evaluation, and paired bootstrap confidence intervals are complete for both `v4-1325` and `v4-5000`.**

Both experiments fine-tune `google/gemma-3-270m-it` (FP32 LoRA, `r=16`, `alpha=32`, 3 epochs) on reduced-schema clinical JSON labels regenerated from the raw clinical notes with `gemini-3.8-flash` and deterministically repaired. Evaluation uses the same 100 frozen development cases (`a331a668a35210b00a75026a9f8be9eecc8fd2532e3eb4a33a181c2d0d6167be`) and the `source_grounded_v2` LLM rubric (`gemini-4-hydrogen`, 400 measurements per run).

### Paired bootstrap confidence intervals (`v4-5000` vs. Base)

From [paired_confidence_intervals.json](../../results_v4_5000/deepeval_100_rp1/judgments/2f58650627fa8d6a/paired_confidence_intervals.json) (paired BCa bootstrap on `2f58650627fa8d6a`):

- **Source fidelity:** `0.323 → 0.619`, mean paired gain **`+0.296`**, 95% BCa CI **`[+0.259, +0.331]`**, Bonferroni 97.5% CI `[+0.253, +0.335]`, **93 wins / 3 ties / 4 losses**.
- **Source coverage:** `0.357 → 0.625`, mean paired gain **`+0.268`**, 95% BCa CI **`[+0.235, +0.298]`**, Bonferroni 97.5% CI `[+0.230, +0.302]`, **95 wins / 2 ties / 3 losses**.

## Key takeaways

1. **Decoding fix (`gen_rp=1.00_fb1.08`):** Removing unconditional repetition penalty `1.08` (keeping it only as a loop-breaker when hitting `2,048` tokens) improved `v4-1325` strict F1 (`28.66% → 29.41%`), soft F1 (`41.17% → 42.03%`), and source fidelity (`0.523 → 0.537`) with zero retraining.
2. **Scaling clean labels (`1,325 → 5,000`):** Scaling regenerated training data to 5,000 examples delivered the largest jump across every metric: schema validity rose from `86/100` to **`97/100`**, strict F1 from `29.41%` to **`40.17%`** (`+10.76 pp`), soft F1 from `42.03%` to **`55.27%`** (`+13.24 pp`), source fidelity from `0.537` to **`0.619`** (`+0.082`), and source coverage from `0.561` to **`0.625`** (`+0.064`), while cutting fallback triggers from `20` to `5` and budget hits from `7` to `1`.
